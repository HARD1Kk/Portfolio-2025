## Run locally

This is a static site — no build step required to view it.

```bash
git clone https://github.com/HARD1Kk/Portfolio-2025.git
cd Portfolio-2025
# open index.html in your browser, or serve it:
python -m http.server 3000
```

> Note: `sass/` holds the Sass source that compiles to `css/style.css`. You only need the
> Sass toolchain if you're editing styles.
