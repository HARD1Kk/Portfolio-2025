A2A ANALYTICS CHATBOT : CONVERSATIONAL DATA ANALYSIS

Conversational data analysis over complex enterprise datasets.

Project Overview

This is a conversational analytics platform that lets people interrogate complex enterprise datasets in plain language. A full-stack Next.js application provides semantic search and conversational analysis, while LangChain pipelines strictly ground every response in verified MSSQL data — so the answers are traceable to real rows, not hallucinated.

The interesting part is the Agent-to-Agent (A2A) framework with adaptive routing. It can spin up a fast path for quick answers ("Fast Mode") or a deeper, multi-agent path for comprehensive information extraction ("Deep Research Mode"), depending on what the question needs.
